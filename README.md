# Map-Taker

«Захват территории» для изучения японского. На топографическом листе генерируется случайный материк или архипелаг. За каждое занятие (грамматика, Anki, чтение, аудио, разговор и т. д.) закрашиваются клетки, пока не захватишь всю карту.

- Карту можно перерисовывать, пока не утвердишь её.
- Объём занятия распознаётся из текста: «повторил 200 карточек в Anki», «Genki II, 32 мин».
- Архив прошлых листов с прокруткой хода захвата.
- Выгрузка и загрузка прогресса в .json, картинка листа в .png.
- Светлая и тёмная тема.

Всё в одном файле `index.html`, без сборки. Прогресс хранится в браузере.
